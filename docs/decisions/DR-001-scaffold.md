# DR-001 — Day 1 scaffold

**Status:** accepted
**Date:** 2026-08-02

## Context

Doctrine §3 lifted the blueprint approval gate; default mode is writing real
code. This record covers only decisions whose reversal cost is non-trivial or
which future work will otherwise relitigate. Everything settled in doctrine §7
is implemented, not decided here.

## Decisions

**D1 — Money is `i64` minor units with a `Currency` tag; rates are `i64` basis
points.** `rust_decimal` was rejected: it is a float-free decimal, but it admits
a division that silently changes scale, and doctrine §5 says integer minor
units specifically. Reversal cost: low, `Money` is a newtype.

**D2 — `Money` deliberately does not implement `std::ops::Add`/`Sub`/`Mul`.**
Those traits are infallible; money arithmetic here can fail on currency mismatch
or overflow. Every call site therefore handles the error. This is verbose on
purpose.

**D3 — One rounding policy, half-away-from-zero, in one function.** Chosen over
banker's rounding because lender amortization tables and HUD schedules publish
half-up figures, so hand-verified fixtures agree to the cent. Changing it is a
one-line diff plus a snapshot review.

**D4 — Amortization compounds in i128 fixed point at 1e12 and rounds once.**
An earlier version of `remaining_balance` rounded two terms separately and was
off by one cent against the oracle; it now puts both terms over a common
denominator. Tests catch this exactly, without a tolerance window.

**D5 — Provenance is `Traced<T>` with `Arc`-shared trace nodes.** Making the
engine return `Traced` rather than bare values means "compute a number without
provenance" is not expressible. `Arc` keeps a full trace cheap enough that no
one is tempted to skip it. `Trace::op` is `Cow<'static, str>` rather than
`&'static str` — the borrowed form forces `'de: 'static` and breaks
deserialization of the generic wrapper.

**D6 — Fair Housing is enforced by a filter inside `Connector::ingest`, and an
undeclared forbidden field is a hard error rather than a silent drop.** A source
that begins shipping a crime index should stop the pipeline and force a visible
decision. Connectors declare intentional drops explicitly, so the decision
appears in a diff.

**D7 — `Connector` cannot be implemented without returning a `RightsPosture`.**
Doctrine §5 requires rights be checked before scraping; the type system now
requires it too.

**D8 — The daemon's bind address is hardcoded to `127.0.0.1` and is not
configurable.** A config option that can expose an operator's deal pipeline to
their LAN has no upside. Port is configurable via `VELT_PORT`; `0` asks the OS
for a free port, which is how the shell avoids a stale-daemon collision.

**D9 — DSCR for an all-cash deal returns `i64::MAX` as an "undefined" sentinel,
not `0`.** Zero would render as "fails coverage", the opposite of the truth.

**D10 — The TypeScript client is generated by a checked-in script from
`openapi.json`, and `just drift` fails CI on any diff.** No codegen dependency
to keep current; the script only transcribes what utoipa emitted.

## CMR impact

None. No decision here forecloses subscription, perpetual license, or
proprietary-edge (doctrine §6). Entitlement, identity, and billing code do not
exist — triggers T1, T2, T3 have not fired.
